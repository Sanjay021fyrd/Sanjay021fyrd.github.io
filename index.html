Things I've built

IntelliQuery AI

Python, FastAPI, React, MongoDB, Groq LLMs, Pandas

You ask a question about your data in plain English and it writes the query for you: SQL for a MySQL or PostgreSQL database, or Pandas for a CSV or Excel file. You get back the result table, the query it generated and, if you want one, a chart.

Because a language model is writing the queries, every one is checked before it runs. SQL may only be a SELECT or WITH statement, generated Pandas code goes through an AST check, and a second LLM pass validates the answer and retries when something looks wrong.

There are user accounts too: JWT in HTTP-only cookies, PBKDF2 password hashing, and saved database credentials encrypted with Fernet. Each user gets their own chat history, 13 kinds of Plotly chart, and CSV or email export.

A team project, the three of us, for our fifth semester.

Hoax Hunter

Python, Streamlit, scikit-learn, Pandas, pytest

Paste an SMS, WhatsApp or email message and it gives you a risk score from 0 to 100, a verdict (Safe, Suspicious or Likely Scam), the red flags it found, the suspicious words highlighted, and what to do next. I made it for parents and grandparents.

Two things work together. A rule engine looks for urgency, requests for an OTP or PIN, fake KYC and prize offers, and lookalike bank links. A TF-IDF and Logistic Regression model was trained on the UCI SMS Spam Collection plus about 165 India-focused messages I wrote by hand. The rules say why they fired, so every verdict can be explained.

On 1,066 messages held back for testing it reached 99.0% accuracy and caught 97.2% of the scams. Most of that test data is older UK and US-style SMS, so I treat the number as optimistic. It has pytest tests, starts with one command, and nothing you paste is stored.
